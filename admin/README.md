# Админ-панель TRAVELER

Удобная система управления контентом для туристического сайта TRAVELER.

## 🚀 Быстрый старт

1. Откройте файл `admin/login.html` в браузере
2. Введите любые данные для входа (демо-режим)
3. Начните управлять контентом сайта!

## 📋 Возможности

### 1. **Панель управления (Dashboard)**
- Статистика по всем разделам сайта
- Последние бронирования
- Быстрый доступ к основным функциям

### 2. **Управление турпакетами**
- Просмотр всех турпакетов
- Добавление новых пакетов
- Редактирование существующих
- Удаление пакетов
- Управление ценами, рейтингами и описаниями

### 3. **Управление направлениями**
- Добавление популярных направлений
- Редактирование информации о городах
- Загрузка изображений направлений
- Удаление направлений

### 4. **Управление блогом**
- Создание новых статей
- Редактирование публикаций
- Управление категориями
- Установка даты публикации
- Удаление статей

### 5. **Управление гидами**
- Добавление информации о гидах
- Загрузка фотографий
- Указание должностей
- Ссылки на социальные сети
- Удаление профилей гидов

### 6. **Управление отзывами**
- Добавление отзывов клиентов
- Редактирование текста отзывов
- Управление фотографиями
- Модерация отзывов

### 7. **Бронирования**
- Просмотр всех бронирований
- Отметка обработанных заявок
- Фильтрация по статусу
- Удаление старых записей

### 8. **Сообщения от клиентов**
- Просмотр контактных форм
- Чтение полных сообщений
- Управление обращениями
- Удаление сообщений

### 9. **Настройки сайта**
- Контактная информация (email, телефон, адрес)
- Ссылки на социальные сети
- Общие параметры сайта

## 💾 Хранение данных

Админ-панель использует **LocalStorage** браузера для хранения данных:
- Все изменения сохраняются локально
- Данные сохраняются между сеансами
- Не требуется сервер или база данных
- Идеально для демонстрации и прототипирования

### Важно:
- Данные хранятся в браузере
- При очистке кэша браузера данные будут удалены
- Для продакшн-версии рекомендуется использовать серверную базу данных

Админ-панель полностью адаптивна и работает на:

- Простая аутентификация через LocalStorage
